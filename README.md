# Matuto Texas · Showroom para lojistas

Site B2B da Matuto Texas, com bonés country e western para lojistas e revendedores.

- Catálogo com filtros, galeria de ângulos e zoom no bordado
- Seleção de atacado que gera a mensagem para o WhatsApp comercial
- Cadastro de lojistas
- Instagram: [@lojamatutotexas](https://www.instagram.com/lojamatutotexas/)

Publicado com GitHub Pages: `index.html` na raiz.
Para editar o número do WhatsApp, o Instagram ou o catálogo, procure `const CONFIG` e `const PRODUCTS` no `index.html`.
